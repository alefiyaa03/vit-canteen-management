# VIT Canteen Management

A command-line based canteen ordering and billing system developed using Python.

## Project Description

This project is a simple canteen management system that allows a user to view the available menu, place an order for multiple items, view the current order, and generate the total bill.

The project demonstrates basic Python programming concepts such as dictionaries, lists, loops, conditional statements, user input, and arithmetic operations.

## Features

- Displays the canteen menu
- Allows the user to select items using item numbers
- Allows multiple items to be added to one order
- Stores ordered items and quantities using a dictionary
- Displays the current order
- Calculates the cost of each item
- Generates the total bill
- Handles invalid item numbers

## Requirements

- Python 3.x
- A command-line terminal
- No external Python libraries are required

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Make sure Python is installed by running:
   python --version

4. Run the program using:

   python main.py

5. The canteen menu will be displayed automatically.
6. Enter the item number and quantity when prompted.
7. Enter 0 when you have finished placing the order.
8. The program will display the current order and generate the total bill.

## Example

The user can select different items and quantities.

    Enter item number (0 to finish): 2
    Enter quantity: 2
    Burger added to your order.

    Enter item number (0 to finish): 3
    Enter quantity: 1
    Pizza added to your order.

    Enter item number (0 to finish): 0

The program then displays the ordered items and calculates the total bill.
